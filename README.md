# ytm-desktop releases

Repo ini hanya berisi **asset rilis** (installer Windows + latest.yml untuk auto-update) dari ytm-desktop.
Source code tidak dipublikasikan di sini.

- Installer terbaru: tab **Releases**
- App yang sudah terpasang mengecek update otomatis (4 jam sekali, terpasang saat Quit)

Catatan: aplikasi personal, bukan produk resmi Google/YouTube. Ikon merek dipakai untuk pemakaian personal non-komersial.
